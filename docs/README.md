# Docs

This directory holds detailed guides and examples that are too long for the root README.

## Structure

- `config/`: Runtime configuration (`.dsoinabox.yaml`) behavior, precedence, examples, and initialization flow.
- `waivers/`: Waiver schema guidance, operational notes, and waiver file examples.

## Conventions

- One top-level directory per topic (`config/`, `waivers/`, etc.).
- Each topic directory should include a `README.md` with concepts + usage.
- Put copy/paste samples under `examples/`.
- Keep root README concise and link here for deep dives.
